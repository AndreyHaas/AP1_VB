# Schreib- und Lernregeln

## Язык

- Объяснение: связный русский текст.
- `Fachbegriffe`: точный немецкий термин без склонения по русским падежам.
- Образец ответа: полное немецкое предложение.
- Не смешивать языки внутри одного предложения, если это создаёт неграмотную конструкцию.

Плохо:

> Система получает введённое Passwort.

Хорошо по-русски:

> Система получает пароль, введённый пользователем.

Хорошо по-немецки:

> Das System erhält das vom Benutzer eingegebene Passwort.

## Структура учебного файла

```text
Frontmatter
# Thema
## Lernziele
## Объяснение
## Deutsche Fachbegriffe
## IHK-Merksätze
## Beispiele / расчёты
## Typische Prüfungsfallen
## Selbsttest
## Lösungen
## Offene Punkte / Korrekturen
```

## Качество

- Не сохранять неверный ответ рядом с правильным без явной маркировки.
- В вычислениях всегда писать единицы.
- `kW` — Leistung; `kWh` — Energie.
- `bit` и `Byte` различаются регистром; `1 Byte = 8 bit`.
- Задание не должно содержать ответ в самой формулировке.
- Сначала объяснение, потом задание; решение открывается только после самостоятельной попытки.
- Таблицы использовать для точных сравнений, но ключевые определения дублировать копируемыми пунктами.

## Git

- Имена файлов: нижний регистр, ASCII, слова через дефис.
- Один тематический смысл — один файл.
- Изменение, подтверждённое преподавателем, фиксируется отдельным commit.
- Сообщение commit писать конкретно, например: `Korrigiere Schlüsselverwendung bei digitaler Signatur`.
