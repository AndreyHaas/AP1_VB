# Fachbegriffe DE–RU für AP1

Stand: 11.09.2026. Рабочий словарь охватывает главы 01–52 и предназначен для активного повторения, а не только для чтения.

## Как учить

1. Закрой колонки с объяснениями и объясни немецкий термин одним полным предложением по-немецки.
2. Проверь смысл по русской колонке.
3. Скажи, в какой задаче термин применяется.
4. Составь Musterantwort с `weil`, `da` или `dadurch`.
5. Термин считается выученным только после двух правильных воспроизведений в разные дни.

Обозначение `Kxx` указывает глобальный номер главы в `AP1-THEMENMATRIX.md`.

## 9. Термины, которые нельзя смешивать

| Nicht verwechseln | Kurzregel |
|---|---|
| Bit / Byte | `1 Byte = 8 bit`; Groß-/Kleinschreibung der Einheit beachten. |
| Leistung / Energie | Watt ist eine Rate; Wattstunde ist eine Energiemenge. |
| Wirkleistung / Scheinleistung | W beschreibt nutzbare Umsetzung; VA elektrische Gesamtbelastung. |
| Bandbreite / Durchsatz | Kapazität ist nicht identisch mit tatsächlich übertragenen Nutzdaten. |
| Latenz / Jitter | Verzögerung ist nicht deren Schwankung. |
| Steckverbinder / Standard | USB-C ist eine Form und keine garantierte Geschwindigkeit. |
| Codec / Container | Codierung ist nicht die Datei-Hülle für Streams. |
| Unicode / UTF-8 | Zeichenzuordnung ist nicht Bytecodierung. |
| Hashing / Verschlüsselung | Hashing ist grundsätzlich nicht mit einem Schlüssel rückgängig zu machen. |
| Signatur / Verschlüsselung | Signatur schützt Zuordnung/Integrität, nicht automatisch Vertraulichkeit. |
| Identifizierung / Authentisierung / Autorisierung | Wer behauptet? Wer beweist? Was darf die Identität? |
| Backup / Redundanz | Wiederherstellungskopie ist nicht bloß Ausfallredundanz. |
| Incident / Problem | Service wiederherstellen versus Ursache bearbeiten. |
| SLA / OLA | Kundenziel versus interne Unterstützungsvereinbarung. |
| ITSM / ISMS | Servicewert/-qualität versus systematische Informationssicherheit. |
| RPO / RTO | tolerierter Datenverlust versus Zielzeit der Wiederherstellung. |
| Rabatt / Skonto | Preisnachlass aus Kondition versus Nachlass für frühe Zahlung. |
| Umsatz / Gewinn | Erlöse sind nicht Erlöse minus Kosten. |
| Lastenheft / Pflichtenheft | Was/wofür aus Kundensicht versus wie aus Auftragnehmersicht. |
| Wireframe / Mockup / Prototyp | Struktur versus visuelles Bild versus testbares Verhalten. |

## 10. Tagesroutine bis zur Prüfung

- täglich 20 neue Begriffe und 20 Wiederholungen;
- Antworten zuerst auf Deutsch, russische Spalte nur zur Kontrolle;
- unsichere Begriffe mit Kapitelnummer markieren und sofort im Kapitel nachlesen;
- jeden fünften Tag ein gemischter 50-Begriffe-Test;
- in Simulationen Fachbegriffe markieren, die in der Antwort aktiv verwendet wurden;
- Ziel: mindestens 80 % freie deutsche Definitionen, bevor ein Themenblock als sicher gilt.
