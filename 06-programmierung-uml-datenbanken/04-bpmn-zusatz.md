# BPMN – Zusatz und noch zu bestätigen

Die IHK beschreibt einen Übergang zu neueren Methoden wie UML oder BPMN. In der detaillierten öffentlichen Vergleichsliste ist für AP1 das UML-Aktivitätsdiagramm eindeutig genannt; der genaue BPMN-Umfang ist ohne vollständigen Prüfungskatalog nicht sicher festgelegt. Deshalb bleibt BPMN in diesem Projekt `P2`, bis WBS oder der offizielle Katalog den Umfang bestätigt.

## Minimales Grundwissen

```text
Start Event / End Event
Task
Sequence Flow
Exclusive Gateway (XOR)
Parallel Gateway (AND)
Pool und Lane
Message Flow zwischen Pools
```

`Sequence Flow` verbindet Ablaufschritte innerhalb eines Pools. `Message Flow` zeigt Kommunikation zwischen unterschiedlichen Teilnehmern/Pools.

## Offene Punkte / Korrekturen

- Umfang mit WBS bestätigen; danach vollständige Beispiele ergänzen oder Thema auf P3 setzen.
