# IPv6

## IPv4 und IPv6

| Merkmal | IPv4 | IPv6 |
|---|---|---|
| Länge | 32 bit | 128 bit |
| Darstellung | dezimal | hexadezimal |
| Beispiel | `192.168.1.20` | `2001:db8::20` |
| Broadcast | vorhanden | kein Broadcast |
| Nachbarschaftsauflösung | ARP | NDP über ICMPv6 |

## Schreibweise verkürzen

Vollständig:

```text
2001:0db8:0000:0000:0000:ff00:0042:8329
```

1. Führende Nullen in jedem Block entfernen:

```text
2001:db8:0:0:0:ff00:42:8329
```

2. Eine zusammenhängende Folge aus Nullblöcken einmal durch `::` ersetzen:

```text
2001:db8::ff00:42:8329
```

`::` darf in einer IPv6-Adresse nur einmal verwendet werden, sonst wäre die Anzahl ausgelassener Blöcke uneindeutig.

## Wichtige Bereiche

| Bereich | Bedeutung |
|---|---|
| `2000::/3` | Global Unicast |
| `fe80::/10` | Link-Local Unicast |
| `fc00::/7` | Unique Local Unicast |
| `ff00::/8` | Multicast |
| `::1` | Loopback |
| `::` | nicht spezifizierte Adresse |
| `2001:db8::/32` | Dokumentation |

Eine IPv6-Schnittstelle besitzt typischerweise mindestens eine Link-Local-Adresse; sie gilt nur auf dem lokalen Link.

## Konfiguration

- `SLAAC`: Client bildet seine Adresse mithilfe von Router Advertisements.
- `DHCPv6`: liefert je nach Verfahren Adressen oder weitere Konfiguration.
- `statische Konfiguration`: manuelle Vergabe.

Das Standardgateway wird bei IPv6 über Router Advertisements gelernt, nicht als normale DHCPv6-Option.

## NDP

`Neighbor Discovery Protocol` übernimmt unter anderem Nachbarschaftsauflösung und Router-Erkennung. Es basiert auf ICMPv6 und ersetzt nicht nur ARP, sondern umfasst weitere Funktionen.

## IHK-Merksätze

> IPv6 verwendet keinen Broadcast; stattdessen werden unter anderem Multicast-Verfahren eingesetzt.

> SLAAC ermöglicht die automatische IPv6-Konfiguration anhand von Router Advertisements.

## Selbsttest

1. Kürze `2001:0db8:0000:0000:0000:0000:0000:0050`.
2. Ordne `fe80::25` einem Adresstyp zu.
3. Welches Verfahren übernimmt bei IPv6 die Nachbarschaftsauflösung?

## Lösungen

```text
1. 2001:db8::50
2. Link-Local-Unicast-Adresse
3. NDP über ICMPv6
```
