# Datenschutz – Grundlagen

## Datenschutz und Datensicherheit

`Datenschutz` schützt personenbezogene Daten und die Rechte natürlicher Personen.

`Datensicherheit` schützt Daten unabhängig vom Personenbezug vor Verlust, Manipulation und unberechtigtem Zugriff.

Merksatz:

```text
Datenschutz schützt Menschen.
Datensicherheit schützt Daten.
```

Beide Bereiche überschneiden sich: technische Sicherheit ist nötig, um personenbezogene Daten zu schützen.

## Personenbezogene Daten

Personenbezogene Daten sind Informationen, die sich auf eine identifizierte oder identifizierbare natürliche Person beziehen.

Beispiele:

```text
Name, Anschrift, Geburtsdatum
E-Mail-Adresse, Telefonnummer
Personalnummer, zuordenbare Kundennummer
IP-Adresse, Standortdaten
Online-Kennung
```

Eine Artikelnummer ohne Bezug zu einer Person ist kein personenbezogenes Datum.

## Besondere Kategorien nach Art. 9 DSGVO

Besonders geschützt sind unter anderem Daten über:

```text
rassische oder ethnische Herkunft
politische Meinung
religiöse oder weltanschauliche Überzeugung
Gewerkschaftszugehörigkeit
genetische Daten
biometrische Daten zur eindeutigen Identifizierung
Gesundheit
Sexualleben oder sexuelle Orientierung
```

Nicht jeder Fingerabdruck ist automatisch Art.-9-Datum; entscheidend ist, ob biometrische Daten zur eindeutigen Identifizierung verarbeitet werden, например при Zugangskontrolle.

## Selbsttest

Ordne zu: A = personenbezogen, B = besondere Kategorie, C = nicht personenbezogen.

1. Diagnose in einer Patientenakte
2. Artikelnummer eines Monitors
3. Kundennummer, die einer Person zugeordnet werden kann
4. Fingerabdruck zur Zugangskontrolle

## Lösungen

```text
1. B
2. C
3. A
4. B
```

## Offene Punkte / Korrekturen

- BDSG und Beschäftigtendatenschutz nur in der von WBS geforderten Tiefe ergänzen.
