# Betroffenenrechte nach der DSGVO

## Rechte

`Information`: Betroffene werden verständlich über die Verarbeitung informiert.

`Auskunft`: Eine Person erfährt, ob und welche Daten über sie verarbeitet werden.

`Berichtigung`: Unrichtige Daten werden korrigiert, unvollständige ergänzt.

`Löschung`: Daten werden unter den gesetzlichen Voraussetzungen gelöscht; Ausnahmen, etwa Aufbewahrungspflichten, sind möglich.

`Einschränkung der Verarbeitung`: Daten bleiben gespeichert, dürfen vorübergehend aber nur eingeschränkt verarbeitet werden.

`Datenübertragbarkeit`: Bestimmte bereitgestellte Daten werden in strukturiertem, gängigem und maschinenlesbarem Format bereitgestellt oder übertragen.

`Widerspruch`: Betroffene wenden sich gegen bestimmte Verarbeitungen, etwa Direktwerbung oder Verarbeitung auf Grundlage berechtigter/öffentlicher Interessen.

`Widerruf der Einwilligung`: Eine Einwilligung wird für die Zukunft zurückgenommen; die vorherige Rechtmäßigkeit bleibt unberührt.

`Beschwerde`: Betroffene können sich an eine Datenschutzaufsichtsbehörde wenden.

`Automatisierte Entscheidungen`: Unter bestimmten Voraussetzungen besteht Schutz vor ausschließlich automatisierten Entscheidungen mit erheblicher Wirkung.

## Widerspruch und Widerruf

```text
Widerruf    → zieht eine zuvor erteilte Einwilligung für die Zukunft zurück
Widerspruch → richtet sich gegen eine Verarbeitung auf bestimmter Rechtsgrundlage
```

## Selbsttest

1. Falsches Geburtsdatum korrigieren.
2. Daten für Anbieterwechsel maschinenlesbar erhalten.
3. Zustimmung zum Newsletter zurücknehmen.
4. Sich bei der Behörde über rechtswidrige Verarbeitung beschweren.

## Lösungen

```text
1. Berichtigung
2. Datenübertragbarkeit
3. Widerruf der Einwilligung
4. Beschwerde
```

## Offene Punkte / Korrekturen

- Fristen und Identitätsprüfung bei Auskunft nur nach WBS-Vorgabe vertiefen.
