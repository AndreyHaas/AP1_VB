Что обязательно различать
Layer 1 — Bits

Здесь передаются только электрические, оптические или радиосигналы:

Кабель повреждён
Нет WLAN-сигнала
Неправильный Stecker
Сетевой интерфейс не показывает Link

Типичные устройства:

Repeater
Hub
Кабель
Антенна
Layer 2 — MAC и Frames

Switch работает преимущественно на Layer 2:

MAC-адрес отправителя
MAC-адрес получателя
Ethernet Frame

Switch запоминает, за каким портом находится определённый MAC-адрес, и отправляет Frame в нужный порт.

ARP определяет MAC-адрес по известному IPv4-адресу:

Кто имеет 192.168.1.1?
Сообщите 192.168.1.20

ARP считается пограничным механизмом между Layer 2 и Layer 3, но в учебных заданиях его часто относят к Layer 2.

Layer 3 — IP и Packets

Router работает на Layer 3:

Source IP
Destination IP
Routing
Default Gateway
ICMP

Router решает, куда дальше передать IP-Packet.

ping использует ICMP, а не TCP и не UDP. Поэтому у ping нет TCP/UDP-порта.

Layer 4 — TCP/UDP и Ports

Порт определяет приложение внутри компьютера:

IP → какой компьютер?
Port → какое приложение на этом компьютере?

Например:

192.168.1.20:51500 → 93.184.216.34:443
51500 — временный Source Port клиента.
443 — Destination Port HTTPS-сервера.

TCP передаёт Segment, UDP — Datagram.

Layers 5–7

Здесь находятся пользовательские данные и прикладные сервисы:

HTTPS → Layer 7
DNS → Layer 7
DHCP → Layer 7
SSH → Layer 7

Важно: DNS использует UDP/TCP, но сам DNS всё равно относится к Layer 7. Протокол одного уровня использует услуги нижнего уровня.

Encapsulation

При открытии сайта данные проходят сверху вниз:

HTTP Data
↓ добавляются TCP Ports
TCP Segment
↓ добавляются IP-адреса
IP Packet
↓ добавляются MAC-адреса
Ethernet Frame
↓ преобразование в сигналы
Bits

На принимающей стороне происходит обратный процесс — Decapsulation.

Короткая последовательность:

Data → Segment → Packet → Frame → Bits
Первое задание по OSI

Укажи номер уровня:

TCP
IPv4
Ethernet Frame
HTTPS
MAC-адрес
Port 443
Router
Обычный Switch
Сетевой кабель
ICMP/ping
DNS
UDP Datagram

Формат ответа:

1–4, 2–3, 3–2...

После этого полностью разберём, что происходит от ввода https://example.de до получения страницы: DNS, ARP, Gateway, TCP Handshake, TLS и HTTP.

1-4,2-3,3-2,4-7,5-2,7-3,8-2,9-1,10-2,11-7,12-4

Отлично: 10 ответов правильные, один пропущен и один нужно исправить.

6. Port 443 → Layer 4
10. ICMP/ping → Layer 3

Разница:

HTTPS — прикладной протокол → Layer 7
Port 443 — транспортный адрес → Layer 4
ICMP работает с IP → Layer 3

У ICMP нет номера порта.

Ключевая цепочка

Layer 3: IP Packet — IP-адреса

При получении данных:

Bits → Frame → Packet → Segment → Data
Типичные ловушки AP1
Вопрос	Правильный ответ
На каком уровне работает обычный Switch?	Layer 2
На каком уровне работает Router?	Layer 3
Где используются MAC-адреса?	Layer 2
Где используются IP-адреса?	Layer 3
Где используются номера портов?	Layer 4
К какому уровню относится DNS?	Layer 7
DNS использует какой Transport?	Обычно UDP, при необходимости TCP
К какому уровню относится ICMP/ping?	Layer 3, портов нет
Что передаёт TCP?	Segment
Что передаёт UDP?	Datagram
Что передаёт Ethernet?	Frame
Где работает ARP?	Между L2/L3, на экзамене обычно Layer 2
Какой MAC у удалённого пакета в локальной сети?	MAC Default Gateway
Какой Destination IP?	IP конечного сервера
