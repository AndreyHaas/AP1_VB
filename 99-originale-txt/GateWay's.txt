GateWay's

Router выбирает путь по Routingtabelle. В ней обычно указаны:

Zielnetz
Netzpräfix
Next Hop / Gateway
Netzwerkschnittstelle
Metrik

Пример:

Zielnetz	Next Hop
192.168.20.0/24	direkt verbunden
192.168.10.0/24	192.168.20.1
0.0.0.0/0	192.168.20.254

Тогда:

Ziel 192.168.20.80 → direkt
Ziel 192.168.10.50 → über 192.168.20.1
Ziel 8.8.8.8       → über Default Route 192.168.20.254

0.0.0.0/0 называется:

Default Route
Standardroute

Она используется, если более точного маршрута нет.

Longest Prefix Match

Если подходят несколько маршрутов, выбирается маршрут с самым длинным, то есть самым конкретным Netzpräfix.

Дано:

Zielnetz	Gateway
10.0.0.0/8	Gateway A
10.20.0.0/16	Gateway B
10.20.30.0/24	Gateway C
0.0.0.0/0	Gateway D

Какой Gateway будет выбран для:

10.20.30.40
10.20.50.40
10.50.30.40
8.8.8.8

| Ziel-IP-Adresse | Подходящий маршрут | Gateway |
| --------------- | ------------------ | ------- |
| `10.20.30.40`   | `10.20.30.0/24`    | C       |
| `10.20.50.40`   | `10.20.0.0/16`     | B       |
| `10.50.30.40`   | `10.0.0.0/8`       | A       |
| `8.8.8.8`       | `0.0.0.0/0`        | D       |

Быстрая проверка без двоичных чисел:

/8  → должен совпасть первый Oktett
/16 → первые два Oktette
/24 → первые три Oktette

Для 10.20.50.40:

10.20.30.0/24 → не подходит: третий Oktett отличается
10.20.0.0/16  → подходит: первые два Oktette совпадают
10.0.0.0/8    → тоже подходит, но /16 точнее
