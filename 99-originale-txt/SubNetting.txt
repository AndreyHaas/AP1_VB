В одном октете веса битов выглядят так:

Как выбрать подсеть для количества устройств

Допустим, клиенту нужно 50 IP-адресов.

Сначала добавляем два служебных адреса:

50 Host + Netzadresse + Broadcast = 52

Ищем ближайшую сверху степень двойки:

2⁵ = 32 — мало
2⁶ = 64 — подходит

Шесть бит остаются для Host:

32 − 6 = /26

Следовательно:

50 устройств → /26
/26 предоставляет 64 адреса, из них 62 для устройств

Теперь три коротких задания:

Какая минимальная подсеть нужна для 25 устройств?
Какая минимальная подсеть нужна для 100 устройств?
Сколько адресов для устройств предоставляет /29?

Для первых двух напиши ход вычисления и подходящий префикс.

moj nekorrektnij otwet:
25+2=27 2w5(32) dostatochno 100+2=102 2w7(128) 16-2=14

otwet kotorij doljen bit':
Первые два расчёта правильные, нужно только дописать префиксы:

Для 25 устройств:
25 + 2 = 27
Следующая степень двойки: 2⁵ = 32
Остаётся 5 Host-бит
32 − 5 = /27

Ответ: /27, доступно 30 адресов для устройств.

Для 100 устройств:
100 + 2 = 102
Следующая степень двойки: 2⁷ = 128
Остаётся 7 Host-бит
32 − 7 = /25

Ответ: /25, доступно 126 адресов для устройств.

Здесь небольшая ошибка:
/29 → 32 − 29 = 3 Host-бита
2³ = 8 адресов
8 − 2 = 6 адресов для устройств
